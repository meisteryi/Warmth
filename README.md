## 📖 서비스 소개 (About Warmth)

> **"소중한 사람들과 실제로 주고받기 위해 만들고 다듬어온 프로덕션 레벨의 웹 애플리케이션입니다."**

**온기(Warmth)**는 둘만의 6자리 고유 코드로 안전하게 연결되어 편지를 번갈아 주고받는 **턴제(Turn-based) 아날로그 교환일기**입니다.  
디지털 화면 속에서도 한 장의 종이를 만지는 듯한 서정적 감성을 위해 **종단간 암호화(E2EE), Web Audio 절차적 사운드, 3D 온기 유리병, Web Push 알림, AI 온기 지수 측정** 등 기술적 디테일을 정교하게 녹여냈습니다.

## 🌟 핵심 기능 및 사용자 경험 (Key Features)

### 🕯️ 3초 롱프레스 실링 왁스 (Wax Seal Interaction)
- 편지 봉투에 찍힌 실링 왁스를 **3초간 길게 누르면(Long-press)** 시각·청각·촉각 피드백과 함께 왁스가 사르르 녹아내리며 편지가 개봉됩니다.
- **Web Audio API 절차적 사운드 합성**: 외부 음원 파일 로딩 없이 브라우저 오디오 노드로 왁스가 지글지글 끓어오르는 저주파 험(`Melt Hum`)과 쩍 갈라지는 파열음(`Wax Crack`), 햅틱 진동을 완벽히 연출합니다.

### 🏺 3D 기억의 온기 유리병 (Three.js 3D Memory Jar)
- 편지를 주고받을 때마다 둘만의 추억이 담긴 형형색색의 실링 왁스 조각들이 유리병 안으로 사르르 떨어집니다.
- **반응형 3D 인터랙션**: 마우스 드래그 및 터치로 유리병을 360도 회전하며 감상할 수 있고, 왁스 알갱이를 터치하면 해당 일기로 바로 이동합니다.

### 🧩 3대 봉인 해제 관문 (Unlock Mission Gates)
편지를 읽기 전, 상대방이 지정한 다정한 미션을 통과해야만 왁스 봉인을 풀 수 있습니다:
1. **🧩 사진 슬라이딩 퍼즐 (Photo Sliding Puzzle)**: 첨부한 사진이 3×3 조각으로 분리되어 손끝으로 맞추는 추억 복원 퍼즐.
2. **📮 빈티지 찢긴 우표 직소 퍼즐 (Torn Stamp Puzzle)**: 대한제국 앤틱 우표가 무작위로 찢겨 흩어지며 회전과 결합으로 완성하는 퍼즐.
3. **❓ AI 감성 추억 퀴즈 (Surprise Memory Quiz)**: 지난 편지들을 바탕으로 Gemini AI가 출제하는 둘만의 소소한 과거 회상 퀴즈.

### 🌡️ Gemini AI 온기 지수 & 감성 해시태그
- **정서적 공기감 분석**: 단순 단어 매칭이 아닌, 글 전체의 서사와 감정의 결을 Gemini 모델이 심층 분석하여 **-20.0°C ~ 40.0°C의 온기 온도**를 측정합니다.
- **다정한 한 줄 헌사 & 키워드**: 글의 분위기를 함축한 시적 코멘트와 감성 해시태그를 일기에 새겨줍니다.

### 📮 둘만의 보관된 서재 & 월말 온기 결산 (Monthly Warmth Recap)
- **둘만의 서재**: 서로 주고받은 모든 편지를 날짜별, 작성자별로 한눈에 읽어볼 수 있는 아늑한 양장본 서재 인라인 뷰.
- **매월 말일 단 한 번의 종합 결산**: 말일이 되면 그달의 모든 일기를 종합하여 **이달의 평균 온기 지수, 대표 우표, 온도 흐름 SVG 차트, 35mm 빈티지 카메라 필름 롤**을 단 한 번 영구 생성합니다.
- **결정론적 35mm 필름 롤**: 상하 스프로킷 구멍이 뚫린 암실 필름 프레임에 사진들을 무작위 셔플하여 고정 배치합니다.

### 🏷️ 1:1 독립 포스트잇(Post-it) & 실시간 자동 임시저장
- **방 & 일기 & 작성자별 1:1 격리**: 일기마다 개별 부착되는 포스트잇 반응으로, 다른 일기나 상대방 화면에 메모가 절대 섞이지 않습니다.
- **기기 재부팅 복구**: 작성 중 브라우저를 닫거나 폰을 껐다 켜도 작성 중이던 메모가 100% 안전하게 복원되며, 부착 즉시 깔끔하게 정리됩니다.
- **미개봉 스포일러 차단**: 상대방이 왁스를 깨기 전까지는 포스트잇 내용이 메모리 레벨에서도 완전히 가려집니다.

### 🔔 실시간 웹 푸시 & 바람 종소리 노크 (Windchime Knock)
- **OS 네이티브 푸시 알림**: 앱을 닫아두어도 새 편지 도착, 편지 개봉, 노크 알림이 백그라운드 푸시로 전달됩니다. (VAPID 키 자동 복구 및 교체 지원)
- **감성 노크(Knock)**: 편지를 보채지 않고 맑은 윈드차임 풍경 소리와 함께 가볍게 노크를 띄웁니다.

### 🖨️ 소책자 PDF 인쇄 (Booklet Printable)
- 둘만의 기념일(100일, 1주년)을 기념하여 모은 일기들을 표지, 목차, 본문 사진이 포함된 정갈한 종이책 레이아웃으로 즉시 인쇄하거나 PDF 파일로 평생 소장할 수 있습니다.

## 🛡️ 보안 및 아키텍처 원칙 (Security & Architecture)

1. **종단간 암호화 (E2EE - End-to-End Encryption)**
   - 모든 일기 제목, 본문, 사진 캡션, 노크 메시지는 클라이언트 단에서 방 고유 솔트(Salt)와 암호화 키로 AES 수준 암호화된 후 Firestore에 저장됩니다.
   - 서버나 데이터베이스 관리자조차 둘만의 비밀 일기를 평문으로 열람할 수 없습니다.

2. **클라이언트 사이드 메모리 마스킹**
   - 아직 왁스를 깨지 않은 미개봉 편지는 개발자 도구(F12 / Network 탭)를 통해서도 본문과 사진을 엿볼 수 없도록 리액트 상태 레벨에서 원천 마스킹됩니다.

3. **원자적 트랜잭션 (Atomic Concurrency Control)**
   - 두 사람이 동시에 편지를 작성하거나 전송하더라도 Firestore `runTransaction`을 통해 턴 충돌(Race Condition)을 완벽하게 방지합니다.

## 🚀 로컬 개발 및 실행 (Getting Started)

### 1. 저장소 클론 및 의존성 설치
```bash
git clone https://github.com/meisteryi/Warmth.git
cd Warmth
npm install
```

### 2. 환경 변수 설정
프로젝트 루트에 `.env.local` 파일을 생성하고 아래 설정값을 입력합니다:

```env
# FIREBASE CONFIG
NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.firebasestorage.app
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id

# GEMINI AI
GEMINI_API_KEY=your_gemini_api_key

# WEB PUSH VAPID KEYS
NEXT_PUBLIC_VAPID_PUBLIC_KEY=your_vapid_public_key
VAPID_PRIVATE_KEY=your_vapid_private_key
VAPID_SUBJECT=mailto:your_email@example.com
```

### 3. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속하여 즉시 테스트할 수 있습니다.

### 4. 프로덕션 빌드 및 전수 무결성 검증
```bash
# Next.js 프로덕션 빌드
npm run build

# 암복호화, 알림, 서재, 포스트잇 종합 무결성 진단
NODE_PATH=./node_modules npx tsx --env-file=.env.local .gemini/antigravity/.../diagnose_all_systems.ts
```
